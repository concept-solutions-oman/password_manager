Frequently Asked Questions

Who can see the passwords?

Only users assigned the Administrator role, or users who have been explicitly assigned to a specific customer/device, can view the passwords. Everyone else is completely restricted.

Are the passwords encrypted in the database?

The module utilizes standard Odoo security mechanisms. Passwords are visually masked on the frontend to prevent shoulder-surfing, ensuring safe daily usage within office environments.

Can I categorize different types of logins?

Yes! You can create unlimited 'Device/Application' types (e.g., FTP, Database, Server, Web Portal) to organize credentials exactly how your team works.

Does this work on Odoo Community and Enterprise?

Yes, this module is fully compatible with both Odoo Community and Odoo Enterprise editions for version 17.0.
