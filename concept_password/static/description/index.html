Rock-Solid Access Control

Security isn't just about hiding passwords; it's about controlling who has the right to see them. Our built-in roles ensure your data stays compartmentalized.

Best Practice: Only give Administrator rights to key managers.

Administrator Role

Full, unrestricted access. Can view, edit, and create all passwords, devices, and manage global configuration settings across all customers.

Assigned Users Only

Restricted access. Users can only view and interact with passwords for customers or devices they have been explicitly assigned to.
