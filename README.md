# Concept Password Management

**Securely manage passwords, devices, and access rights for customers.**

This Odoo module provides a centralized and secure way to store and manage credentials for your customers' devices and applications.

## Key Features

*   **🔒 Secure Storage**: Passwords are masked by default and only visible to authorized users.
*   **👥 Access Control**:
    *   **Administrator**: Full access to view and edit all passwords.
    *   **Assigned Users**: Can only access passwords for customers or devices they are assigned to.
*   **📋 Detailed Records**: Store URL, IP Address, Username, Password, and Description.
*   **🚀 Smart UI**:
    *   **One-Click Copy**: Quickly copy credentials to clipboard.
    *   **Clickable URLs**: Direct links to login pages.
    *   **Sidebar Filters**: Easily filter by Device or Customer.
*   **📱 Device/Application Management**: Categorize passwords by device or application type.

## Usage

1.  **Define Access Rights**: Go to *Settings > Users* and assign "Password Management" roles (Administrator or Assigned passwords only).
2.  **Create Devices**: Go to *Password Manager > Configuration > Device/Applications* to define types (e.g., Server, FTP, CMS).
3.  **Add Passwords**: Go to *Password Manager > All Passwords* and click New. Select a Customer and fill in the details.

## Installation

1.  Install the module.
2.  Upgrade to load all assets and views.
3.  Assign user groups.
